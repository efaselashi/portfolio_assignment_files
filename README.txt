PORTFOLIO ASSIGNMENT — READ BEFORE SUBMISSION

2. Open index.html in a browser (Live Server is recommended).
3. Replace the placeholder profile image and project screenshots in images/.

9. Push the portfolio folder to a PUBLIC GitHub repository named portfolio.
